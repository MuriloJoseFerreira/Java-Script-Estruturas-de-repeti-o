# Exercícios de Laços de Repetição

Soluções de 10 exercícios de JavaScript usando prompt(), alert() e confirm(), com HTML e JavaScript em arquivos separados.

## Estrutura

- html/ : uma página HTML para cada exercício
- js/ : um arquivo JavaScript para cada exercício

Cada página em html/ carrega o script de mesmo número na pasta js/. Mantenha as duas pastas lado a lado.

## Como usar

1. Extraia o conteúdo do zip.
2. Abra qualquer arquivo da pasta html/ no navegador.
3. Clique no botão Executar e siga as instruções que aparecerem na tela.

## Exercícios

1. Senha com repetição até acertar
2. Senha com no máximo 3 tentativas
3. Validação de idade entre 0 e 120
4. Números ímpares de 1 até um limite
5. Contagem regressiva até Decolar
6. Contagem de pares e ímpares em 6 números
7. Média de idades com confirm()
8. Maior e menor entre 5 números
9. Caixa de mercado com cálculo de troco
10. Anos para a população do país A alcançar a do país B
